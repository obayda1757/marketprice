TROUBLESHOOTING QUICK REFERENCE
================================================================================

Issue: Plugin not showing
   Solution: Check activation, verify file permissions (755 folders)

Issue: No data displaying
   Solution: Verify CSV URL is public and accessible

Issue: Charts not rendering
   Solution: Clear WordPress and browser cache, refresh page

Issue: Settings won't save
   Solution: Check admin permissions, verify nonces are enabled

Issue: Mobile view broken
   Solution: Clear cache, test in incognito mode

Issue: Styling conflicts
   Solution: Check for conflicting CSS, clear cache

Issue: Filters not working
   Solution: Verify CSV has Category/Year data

CSV DATA FORMAT
================================================================================

Required Columns (in order):
   Sl, Item, Specification, Category, Year, Price, Unit

Example Row:
   1, Rice, Premium Basmati, Cereals, 2024, 450, per kg

Column Details:
   Sl              - Row number (integer)
   Item            - Product name (text, required)
   Specification   - Product variant (text, optional)
   Category        - Product category (text)
   Year            - Year of record (integer, required)
   Price           - Numerical price (number, required)
   Unit            - Measurement unit (text, optional)

Minimum 10 rows recommended for charts
