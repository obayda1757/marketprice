INSTALLATION STEPS
================================================================================

Quick Install (3 minutes):

1. Upload
   ├─ Extract: market-price-dashboard-plugin/ folder
   ├─ Upload to: /wp-content/plugins/
   └─ Result: /wp-content/plugins/market-price-dashboard-plugin/

2. Activate
   ├─ WordPress Admin → Plugins
   ├─ Find: Market Price Dashboard
   └─ Click: Activate

3. Display
   ├─ Create/Edit any Page
   ├─ Add: [market_price_dashboard]
   └─ Publish

✅ LIVE! Dashboard displays with default Google Sheet data.

Optional Custom CSV:
   1. Go: Price Dashboard → Settings
   2. Enter: Your CSV URL
   3. Save: Settings
   4. Done: Dashboard updates
