## Installation (3 Steps)

### Step 1: Extract & Upload
```
Extract: market-price-dashboard-plugin/
Upload to: /wp-content/plugins/
Result: /wp-content/plugins/market-price-dashboard-plugin/
```

### Step 2: Activate
```
WordPress Admin → Plugins
Find: "Market Price Dashboard"
Click: Activate
```

### Step 3: Display
```
Create any Page
Add: [market_price_dashboard]
Publish
```

**✅ LIVE!** Dashboard displays with default data.
